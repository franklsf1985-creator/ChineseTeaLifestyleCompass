# 中国茶生活风格罗盘 · Chinese Tea Lifestyle Compass · 중국 차로 알아보는 나의 티 라이프 스타일

以中国茶文化和生活美学为主题的三语（简体中文 / 한국어 / English）Streamlit 网页应用。
通过 10 道情境选择轴题目，为用户匹配六种茶生活风格（主要风格 + 辅助风格），
并给出茶品、冲泡、茶具与场景建议。

本测试仅用于茶文化体验、生活灵感与娱乐，不构成专业心理评估或健康建议。

## 文件结构

```
├── app.py                  # 单文件应用：访问验证、三语文案、题目数据、风格结果、计分与页面逻辑
├── requirements.txt        # 仅依赖 Streamlit
├── .streamlit/config.toml  # 低饱和主题配色（与 app.py 内 CSS 一致）
└── README.md
```

## 本地安装依赖

```bash
pip install -r requirements.txt
```

## 本地启动

```bash
streamlit run app.py
```

启动后浏览器访问终端提示的地址（默认 http://localhost:8501）。

## 部署到 Streamlit Community Cloud

1. 将本目录推送到一个 GitHub 公开仓库（至少包含 `app.py` 与 `requirements.txt`）。
2. 登录 <https://share.streamlit.io>，选择 **New app**。
3. 选择对应仓库、分支，并将主文件路径设置为 `app.py`。
4. 点击 **Deploy**，等待构建完成即可获得应用链接。
5. 之后每次向该分支推送代码，线上应用会自动更新。

## 功能概览

- 语言选择与访问码登录 → 测试介绍 → 10 道情境题 → 测试结果。
- 四种选择轴题型：频率轴 ×2、意愿轴 ×2、符合程度轴 ×2、双端偏好轴 ×4。
- 每题答案为 0 起的整数索引；奇数级轴默认居中，偶数级轴默认靠近中间（题目数据中明确记录）。
- 计分采用主要 + 辅助关联风格双权重数组，约三分之一题目反向计分；
  各风格理论最高分不同时先标准化再排序；同分时优先比较第 5、10 题（核心情境题），
  仍相同则按固定风格顺序处理。
- 切换语言保留登录状态、答案、轴位置与测试结果；重新测试恢复默认索引并清除旧结果；
  退出登录清除全部测试状态。
